# Scientific validation evidence

These topic archives preserve exact original file bytes and include a `MEMBERS.json` catalog withSHA256. Extract any topic into a fresh local folder for inspection. The archived paths preserve experiment identities; they are not a promise that every historical script is portable without configuration.

| Archive | Scientific question |
| --- | --- |
| `geometry_mms_01.zip` | Retained-domain moments, independent polynomial/energy checks, four manufactured fields on the two interface graphs, calibration checks and finite single-patch references |
| `interfaces_01.zip` | Matched-support/reference comparisons, independent physical-work/Green ledgers, negative controls, raw strong-flux observations and their parameter controls |
| `engineering_01.zip` | Coarser-level saved fields, engineering displacement/stress comparisons and sample-based convergence evidence |
| `quadrature_*.zip` | Observed span moments, integration-order response, actual coefficients, the nine accuracy/work strategies and original interleaved timing observations |
| `mapping_01.zip` | Accepted/finally-used mapping counts, actual input/point qualifications, source-family identities and recorded failed controls |

Current interface table/plot data, all16 graph/level comparisons and48 endpoint vectors are also directly readable under `data/tables/`. Files beginning `HISTORICAL_REFERENCE_` are explicitly retained reference-mismatch controls, not the corrected reference.

Full finest-level fields are in the83 plot inputs: panel30,818 fixed samples and hull132,372 fixed samples. Their vector components and both face-stress tensors are retained. NativeODB duplicates and unused bulk integration-point observers are unnecessary for those data and are not redistributed.

PASS/FAIL labels refer only to the recorded test and original input identity. Strong-flux and finite-work norms have distinct test spaces. Local bending and stress-peak limitations remain in the data. Unexecuted relocation checks are not asserted to have passed.
