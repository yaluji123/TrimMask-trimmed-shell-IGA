# CAD models

TheDWG files are the baseline triangle, complex plate and1x engineering input models; IGES files are exchange geometry. Baseline executed profiles retain their actual source family. The five exact current engineering recipes use the case-specific models in data/cad_models.zip, as recorded in data/CAD_MODELS.json and PAPER_REPRODUCTION_CASES.json. Geometry exchange files do not substitute for a complete physical profile.
